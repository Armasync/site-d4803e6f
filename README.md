موقع يعرض مقطع أنمي قتالي مدته ١٢٠ ثانية يُرسم لحظياً على Canvas داخل المتصفح، مع مؤثرات صوتية مولّدة بـ Web Audio دون أي ملفات صوت أو فيديو.

## ما يوجد في الموقع

- **شاشة البداية**: عنوان «مواجهة الفجر»، بطاقتا المقاتلَين (رين / كورو)، وشرح الفصول الستة.
- **المشغّل**: ساحة ليلية بنيون طوكيو، شريطان للطاقة، شريط تقدم، عنوان الفصل، عدّاد الإطارات، وترجمة الحوار.
- **التحكم**: تشغيل/إيقاف مؤقت، إعادة، ملء الشاشة، كتم الصوت، والنقر على شريط التقدم للتنقل في أي لحظة.
- **بطاقة النهاية**: الفائز، إحصاءات (عدد الضربات، هجمات الطاقة، إطارات التأثير) وإعادة المشاهدة أو الانتقال إلى آخر ٢٠ ثانية.

## البنية

| الملف | الوظيفة |
| --- | --- |
| `index.html` | شاشة البداية، المشغّل، بطاقة النهاية |
| `css/style.css` | كل التنسيقات على لوحة «نيون طوكيو» |
| `js/timeline.js` | الفصلان ١ و٢ من السيناريو + دوال العيّنة (sample) |
| `js/timeline2.js` | الفصول ٣ إلى ٧ (٤٦–١٢٠ ثانية) |
| `js/render.js` | محرك الرسم: خلفية، أفق مدينة، شخصيتان بمسارات، جزيئات، أشعة، وميض |
| `js/audio.js` | مؤثرات صوتية مركّبة بـ Web Audio |
| `js/app.js` | المشغّل: الحلقة الزمنية، الأحداث، الواجهة، الاختصارات |

## الاختصارات

`مسافة` إيقاف/متابعة · `F` ملء الشاشة · `M` كتم · `R` إعادة · `→` `←` تنقّل ٥ ثوانٍ.

المشروع ملفات ثابتة بالكامل (HTML/CSS/JS) ولا يحتاج أي خادم.
